# 一起歪一點

- 人數：2–4 人一組，每人一台平板或手機；老師電腦打開網頁投影
- 時間：約 12 分鐘（5 關），加上關卡間的小討論約 15 分鐘
- 玩法：一塊會傾斜的木盤迷宮，每個人只管一個方向（北、東、南、西），按住就讓木盤往那邊低。大家要一起說好誰先按、按多久、誰負責煞車，才能把彈珠送回家。五關分別是熱身、S 形小路、洞洞路、停穩打卡、大風吹。2 人時每人管兩個方向，3 人時 3 號管南和西。

## 怎麼開始
1. 老師電腦打開遊戲網址，就是老師畫面。依各組人數按「4 人／3 人／2 人」開房間，一組一間。
2. 學生用平板或手機的相機掃自己那一組的 QR code。
3. 學生選號碼。一台裝置只能選一個號碼，被選走的號碼會鎖住；學生畫面只有自己方向的按鈕。
4. 到齊後按「開始第一關」。按「投影這一間」可以放大給全班看，木盤邊緣亮起的顏色就是誰正在按。

## 連線方式與隱私
- 老師電腦的網頁分頁就是房間主機，學生裝置透過 WebRTC 直接連到老師電腦。PeerJS 的公用連線服務只負責牽線，連不上時會經由 PeerJS 的公用轉送伺服器。
- 不收姓名，只有 1～4 號；遊戲資料只在老師的分頁裡，關掉就清空。
- 老師電腦和學生裝置都要能上網。上課中請不要重新整理或關掉老師的分頁。
- 結局會列出每關時間、掉落次數、兩邊同時按的「拔河」次數、沒力次數，以及每個人按住按鈕的時間，並附小組回顧問題。
