# 一起歪一點

- 人數：2–4 人一組，共用一台平板（平放在桌子中間，每人坐一邊）或一台電腦鍵盤
- 時間：約 12 分鐘（5 關），加上關卡間的小討論約 15 分鐘
- 玩法：一塊會傾斜的木盤迷宮，每個人只管一個方向的按鈕（北、東、南、西），按住就讓木盤往那邊低。大家要一起說好誰先按、按多久、誰負責煞車，才能把彈珠送回家。五關分別是熱身、S 形小路、洞洞路、停穩打卡、大風吹。2 人時每人管兩個相鄰方向，3 人時 3 號管南和西。
- 鍵盤：北 Q、東 P、南 M、西 Z（方向鍵也可以）
- 結局會列出每關時間、掉落次數、兩邊同時按的「拔河」次數、沒力次數，以及每個人按住按鈕的時間，並附小組回顧問題。
