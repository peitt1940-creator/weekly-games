# 我的山頂

- 對象：國小三到六年級，個人遊玩
- 時間：約 10 分鐘
- 玩法：校外教學爬松果山步道（虛構），路上有涼亭、瀑布、山頂三個蓋章點。出發前先看告示牌、問學長、打開背包、感覺自己的身體，再到林老師那裡寫目標卡（走到哪裡、幾點以前到）。一開始體力和水量都是「？」，要自己去看才會知道。路上的檢查站會告訴你照現在的速度幾點會到，可以照原計畫走，也可以改目標；累了可以喝水、坐長椅。中午 12 點不管走到哪裡都要停下來。在自己訂的地點蓋到章就是成功結局，最後林老師會依你一路上的紀錄給回饋。
- 操作：方向鍵／WASD 移動，空白鍵或「查看」互動，B 或 🎒 開背包；手機用畫面上的十字鍵與按鈕。
