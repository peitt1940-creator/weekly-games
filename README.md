# 每週遊戲原型

每週一、三、五自動產生的遊戲原型，給課程設計參考用。每款遊戲放在自己的資料夾，打開 `https://peitt1940-creator.github.io/weekly-games/<資料夾名稱>/` 就能玩。

- 週一：2D RPG
- 週三：合作體驗
- 週五：熱門玩法改編

總目錄：https://peitt1940-creator.github.io/weekly-games/

覺得值得正式化的遊戲，會另外開獨立 repo。

## 規則

- 只放遊戲程式、素材與說明文件
- 不放任何學生、家長、教師的個人資料，也不放帳號密碼或 API 金鑰
