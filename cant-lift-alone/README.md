# 一個人搬不動

- 對象：國小三到六年級
- 時間：約 10 分鐘，個人遊玩（電腦、平板、手機皆可）

## 玩法

園遊會開場前，你要把紙杯箱、飲料箱、冰桶推到班級攤位，還要把招牌掛上去。紙杯箱自己推得動，另外兩箱太重，一個人推不動。

- 方向鍵／WASD 或畫面按鈕移動，走進箱子就是推；箱子卡住時按「箱子歸位」。
- 走到人旁邊按空白鍵或「查看」說話。找人幫忙時可以選怎麼開口：只說「幫我一下」，對方會反問；說清楚要幫什麼、到哪裡、大概多久，對方才知道能不能幫。
- 有人會因為自己也在忙而拒絕你；也有人需要你先幫他。
- 結局會列出你開口說過的話、被拒絕時心裡的念頭，最後有一題沒有標準答案的反思題。
