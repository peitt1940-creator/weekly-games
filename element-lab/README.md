# 小小元素實驗室

- 對象：國小三到六年級
- 時間：約 10 分鐘（五個任務箱，每箱 1–2 分鐘；另有不限時的自由實驗室）
- 裝置：電腦滑鼠或手機、平板觸控皆可，單一 HTML 檔，不需安裝、不連後端

## 玩法

在黑色實驗箱裡用手指或滑鼠「畫」出沙、水、火、冰、鹽、種子，每一格都會依規則落下、流動、上飄或起反應。五個任務箱各有限量材料和一個目標：

1. 乾巴巴的花圃：種子碰到水才會發芽，讓植物長到 80 格
2. 森林小屋冒煙了：用水或沙子把火弄熄，小屋要留下一半以上
3. 做一片玻璃窗：沙子碰到很燙的爐子會變成玻璃，熱會往上傳但越傳越弱
4. 隔壁的空水池：讓水蒸氣在冰上凝結成水滴，飛過牆滴進右邊水池
5. 冰凍寶箱：倒水會讓冰塊變大，撒鹽才能把冰融掉

每個任務開始前要先「猜猜看」，完成後對照預測與實驗結果。第一次觀察到的反應會收進發現圖鑑（共 9 種），結局頁附三題回顧問題。

## 改編自

改編自 [Sandboxels](https://neal.fun/sandboxels/)（「落沙／元素沙盒」類遊戲）的玩法機制：每一格是一種元素，元素依簡單的規則移動，相鄰元素會互相反應，複雜現象從簡單規則中自己長出來。靈感來源：[The HN Arcade Newsletter（Issue 4）](https://buttondown.com/andrewgy8/archive/issue-4/)。

本作只借用這個機制概念，另外加上限量材料、任務目標、先預測再驗證、發現圖鑑；元素規則、關卡、文字與程式全部重新撰寫，未使用原作的程式碼或素材。
