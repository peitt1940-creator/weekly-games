# 拼回那十分鐘

- 人數：2–4 人一組，每人一台平板或手機（各開同一個網址，選不同號碼）
- 時間：約 15 分鐘（4 關推理＋心裡話＋小組決定），之後可接 10 分鐘討論
- 對象：國小三到六年級

## 玩法
下課回來，班上做了三個下課的紙橋倒在地上，大家都說是阿布弄的。小組成員分別是時間員、地圖員、耳朵員、物證員，每台平板只看得到自己那一種線索。

1. 先選組別人數和號碼（2 人時每人管兩個角色，3 人時 3 號管兩個）。選了之後這台就不能換號碼。
2. 選好號碼就會看到自己的身分和第一個提示。每關要一個地方一個地方去查：查完一個，下一個地方才會出現，有些地方查了什麼都沒有。自己的地方都查完，作答區才會打開。
3. 每關線索分散在不同人手上，只能用說的互相交換，不把平板拿給別人看。
4. 每個人都要在自己的平板上輸入答案。答對會出現圖案，全組圖案照 1～4 號排好才打得開下一關，所以每個人都得答對。
5. 四關：排時間順序 → 找出先壞的橋腳與原因 → 弄清楚「壞掉也好」在說什麼 → 選出完全對得上線索的說法。
6. 最後每人拿到一位角色的心裡話（米米、阿布、豆豆、小樹），輪流唸給組員聽，再一起決定先做哪兩件事。

送錯答案要等 15 秒才能再送，並會出現「小提示」按鈕。

## 給老師
- 老師預覽（四個角色的線索與答案全看得到）：網址後面加 `?teacher=1`
- 重設某台平板的號碼與進度：頁面最下面「老師重設這台」，老師碼 `1010`
- 進度只存在這台裝置的瀏覽器，沒有連線、不收姓名
