# 一隻接一隻

- 對象：國小三到六年級，個人或兩人討論
- 時間：約 10 分鐘（6 關）
- 玩法：4×4 的夜市廣場上散著青蛙、蜜蜂、兔子、烏龜、貓頭鷹，每種動物走法不同（直線、斜線、日字跳、一格、直斜皆可）。點一隻動物，再點牠走得到的另一隻，牠就把對方背起來；每一步都一定要背到人，不能停在空格。廣場上只剩一隊就過關。可以退一步、重來，或問船夫提示。
- 學習重點：邏輯推理、往回推（倒推）、規則歸納（步數永遠是動物數量少 1）、先預測再驗證。

## 改編自
改編自「用西洋棋子清空棋盤」類型的單人益智遊戲（itch.io 熱門網頁益智遊戲中「Clear the board using chess pieces」一類，以及 Solitaire Chess 的「每步都要吃子、最後只剩一子」機制），只借用這個玩法機制。主題、動物角色與走法名稱、美術、文字、關卡（由自寫求解器挑選）全部原創，沒有使用原作程式碼或素材。
