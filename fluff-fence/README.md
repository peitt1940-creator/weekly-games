# 毛球圍圍看

- 對象：國小三到六年級（個人或兩人一組討論）
- 時間：約 10 分鐘，共 5 關
- 玩法：每關只有幾根柵欄，點草地放柵欄，把毛球圍起來，再按「放出毛球」看結果。毛球只會上下左右滾，碰到草地邊緣就會跑掉；圍住的格子就是分數，圍到三葉草再加 3 分。石頭和池水可以當現成的牆。分數越高星星越多，三顆星會解鎖該關的「發現」。
- 可對應課程：面積與周長、空間推理、最佳化（同樣材料圍出最大面積）、試錯與修正策略。
